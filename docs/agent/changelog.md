*2026-06-01 (later, on `master`) — Security headers. Expanded `public/_headers` into a full Content-Security-Policy (`object-src 'none'`, `base-uri 'self'`, a tight `script-src`, and the site's real img/media/frame/connect sources: Sanity, YouTube, Vimeo, Google Maps, Web3Forms, Cloudflare analytics), HSTS with `preload` (max-age 2y), and tightened `frame-ancestors` to `'self'` (the Studio preview was removed). Addresses the unscored Lighthouse security recommendations; verified via `wrangler dev` with no CSP breakage on home + contact (cross-origin map + form).*

*2026-06-01 (later, on `master`) — Security headers. Expanded `public/_headers` into a full Content-Security-Policy (`object-src 'none'`, `base-uri 'self'`, a tight `script-src`, and the site's real img/media/frame/connect sources: Sanity, YouTube, Vimeo, Google Maps, Web3Forms, Cloudflare analytics), HSTS with `preload` (max-age 2y), and tightened `frame-ancestors` to `'self'` (the Studio preview was removed). Addresses the unscored Lighthouse security recommendations; verified via `wrangler dev` with no CSP breakage on home + contact (cross-origin map + form).*

*2026-06-01 (later, on `master`) — Content-editability remediation (audit + fix). An audit (`docs/agent/content-audit-2026-06-01.md`, `scripts/audit-field-population.mjs`) found most page body-copy fields were empty in Sanity (Studio showed blank inputs while the site rendered the inline code fallbacks), plus a set of orphaned fields and truly-hardcoded items. Fixes, in phases: (A, schema) added an editable closing-CTA `finalCta` button to the shared church-page factory + the events/sermons/contact singletons so the bottom CTA button is editable on every page (it was a hardcoded literal in all 19 templates); removed dead orphan fields (`aboutPage` story\*, `contactPage` whatToExpect\*); fixed the 404 page's stale interior-designer defaults. (B, wiring) every `<FinalCta>` now reads `page.finalCta` (falling back to the prior literal); the 7 pages that hardcoded their `<title>`/meta description now read `seoTitle`/`seoDescription`; the home hero's long-orphaned `heroPrimaryCta`/`heroSecondaryCta` buttons are wired. (C, seed) re-ran `seed-page-lists.mjs` (its published patches had 404'd before the docs existed) and added `seed-page-copy.mjs` + `page-copy.json`, seeding 185 body-copy fields with copy extracted verbatim from the templates. Verified zero drift: a pre-seed vs post-seed build diff was byte-identical across all 29 HTML pages, and field population jumped (e.g. homePage 8→24, beliefsPage 4→35, worshipPage 4→28 of their fields set). No visual change; `typegen` + `studio:deploy` run. Still hardcoded (a later pass): in-body section images (home Welcome, about murals, worship Tiffany, music organ), the home events-teaser headings, contact phone/email/office-hours (from site.ts), and some event/sermon detail fields (cost, registrationLabel, contact, sermon image).*
